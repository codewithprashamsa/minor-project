# Major Project Proposal

**Open-Set Malware Traffic Classification Using 1D-CNNs and JA4 Fingerprinting**

Khwopa College of Engineering, Tribhuvan University

## Overview

This proposal outlines an open-set malware traffic classification framework that combines JA4 TLS fingerprinting with a 1D-Convolutional Neural Network (1D-CNN) and softmax confidence-thresholding for rejection of unknown traffic.
